# 1.1.1

- Інтерфейс успадковує активну тему Home Assistant через Ingress: фон, картки, текст, поля, акцент та шрифт.
- Підтримка перемикання теми без перезавантаження та системної теми поза HA.
- Семантичні кольори графіка залишаються узгодженими з легендою.

# 1.1.0

- Спільна адреса дому, змінює лише адміністратор HA.
- Пошук міста, вулиці й будинку.
- Особисті сповіщення з підтвердженням телефона одноразовим кодом.
- Три незалежні опції: ранковий графік, за 30 хв до відключення, за 30 хв до очікуваного відновлення.
- Серверний планувальник і збереження підписок у /data; YAML експорт прибрано.
- Підтримка звичайних користувачів Ingress, перевірка довіреного проксі та прав адміністратора.
- Новий необхідний дозвіл: Home Assistant Core API.

# 1.0.0

- Початковий застосунок для Home Assistant OS, amd64 та aarch64.
- Графік на сьогодні / завтра з API ТОЕ, автоматичне визначення черг.
- Окремий екран адреси й налаштувань ранкових повідомлень.
- Відносні адреси ресурсів для Ingress, без відкриття порту на хості.
