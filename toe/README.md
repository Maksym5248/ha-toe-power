# Світло вдома

Після встановлення запустіть застосунок і натисніть «Відкрити вебінтерфейс». Увімкніть показ у бічній панелі, якщо хочете відкривати графік із меню Home Assistant.

У «Налаштуваннях» виберіть місто, вулицю та точний номер будинку. Натисніть «Зберегти й показати графік». Адреса зберігається у браузері конкретного пристрою, а не глобально для всіх користувачів HA. Графік оновлюється кожні 5 хвилин.

## Сповіщення

Ця версія ще використовує експорт пакета Home Assistant. Перемикач сповіщень не викликає HA API. Завантажте пакет, установіть у `/config/packages/toe_morning.yaml` та перевірте конфігурацію. Для повідомлень на телефон задайте власну дію `notify.mobile_app_...`; початкове значення створює повідомлення лише всередині HA. Час типово 09:00, часовий пояс HA повинен бути Europe/Kyiv.

Інсталяція add-on сама по собі не встановлює автоматизацію сповіщень. Токенів Home Assistant застосунок не потребує.

## Оновлення

Оновіть інформацію магазину й установіть доступну нову версію. Перед оновленням рекомендовано створити резервну копію звичайними засобами HA. Самого натискання «Перезапустити» недостатньо для отримання нового коду.

Підтримуються 64-бітні amd64 та aarch64 системи. Прямий порт у мережу не відкривається: доступ через Ingress із входом Home Assistant.
